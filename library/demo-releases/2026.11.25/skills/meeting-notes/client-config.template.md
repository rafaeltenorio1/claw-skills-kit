# meeting-notes: settings (Layer 2)

Standards apply without asking; a client can request a change for their instance.

## Standards
| Setting | Standard |
|---|---|
| source_only | Use only what is in the notes. Never add facts, names or dates. |
| missing_owner | An action item without a clear owner is marked "owner: to confirm". |

## Client answers
| Setting | Comes from | Suggested answer | Value |
|---|---|---|---|
| summary_style | Q1 | Five short bullet points | |
| action_item_format | Q2 | Task, owner and due date, one per line | |
| summary_language | Q3 | The same language as the notes | |
